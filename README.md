# How to run

Firstly git clone this repository

```
git clone https://github.com/an-iq-too-high/StupidDat
```
Then ALL files will be downloaded so say this

```
cd StupidDat
```

Once you do it you can choose one from the bottom

```
Ruby = ruby stupiddat.rb
Python = python3 stupiddat.py
C++ = ./cpp_stupiddat
C = ./c_stupiddat
JavaScript = node stupiddat.js
Java = java stupiddat.java
```
***Note: there's some dependencies that you'll need for each one***
